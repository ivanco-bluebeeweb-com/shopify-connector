# Shopify Connector — идеальный первый запуск

Источник: `ONBOARDING_FIRST_LAUNCH_STANDARD.md`. Целевой пользователь: владелец/
операционный менеджер интернет-магазина на Shopify.

## 1. Credential type
API key + домен (`shop_domain` + `access_token` — Custom App Admin API token).

## 2. Идеальный флоу
1. **Первое открытие** — `Empty` со ссылкой "Settings > Apps and sales channels >
   Develop apps > Create an app" и списком нужных Admin API scopes сгруппированных по
   функции (заказы, товары, клиенты, склад) — так владелец магазина, часто без
   технического бэкграунда, понимает какие галочки ставить.
2. **Форма** — domain (placeholder `my-store.myshopify.com`, с явной валидацией
   формата на лету — частая ошибка: вставляют полный URL с https://) + access token.
3. **После успеха** — `get_store_summary` сразу — товары/заказы/выручка/клиенты одним
   экраном, максимально наглядно для не-технического владельца.
4. **Multi-store** — идеально: агентство/сеть с несколькими магазинами — быстрый
   переключатель между подключёнными магазинами в шапке с мини-сводкой по каждому.
5. **Ошибка "shop not found"** — если домен введён с опечаткой или без .myshopify.com —
   конкретное сообщение "магазин с таким адресом не найден — проверьте домен", не
   общая 404.
6. **Scope insufficient** — Shopify Admin API токен может не иметь прав на конкретный
   ресурс (напр. только read_products без read_orders) — конкретный список того, что
   не хватает, а не глухая 403 на конкретном вызове функции.
